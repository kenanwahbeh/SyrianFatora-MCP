API & Webhooks

واجهة المطوّرين

واجهة REST كاملة و Webhooks موقّعة لقراءة وإدارة مساحة عملك على SyrianFatora. تُصادَق باستخدام مفتاح خاص بمساحة العمل، قيّده بصلاحيات، وجرّب كل نقطة نهاية مباشرةً بالأسفل.

في هذه الصفحة
الدليل نظرة عامة المصادقة وحدة الاختبار الحدود والحصة الـ Webhooks الأخطاء الموارد العملاء الفواتير الأصناف عروض الأسعار إشعارات الدائن المدفوعات الفواتير المتكرّرة المصروفات المورّدون فئات المصروفات أسعار الصرف الأسئلة الشائعة

نظرة عامة

تُتيح الواجهة الوصول إلى البيانات نفسها التي تراها في التطبيق — محصورةً في مساحة عمل واحدة بحسب المفتاح المستخدم. الواجهة هي كيف تسحب أنت وتُرسل البيانات؛ والـ Webhooks هي كيف نُشعِرك نحن لحظة وقوع الأحداث.

الرابط الأساسي

https://syrianfatora.com/api/public/v1

الاصطلاحات

  • كل طلب محصور في مساحة العمل المالكة للمفتاح — والمعرّفات من مساحات أخرى تُعيد 404.
  • لا تُرسل الإجماليات أبدًا. تُحتسب المبالغ والضريبة والإجماليات في الخادم من الكميات وأسعار الوحدة والأسعار التي ترسلها.
  • التواريخ بصيغة YYYY-MM-DD؛ والطوابع الزمنية بصيغة ISO-8601. وتُعاد القيم المالية العشرية كنص بدقّة ثابتة.
  • تُقسَّم القوائم لصفحات عبر ?per_page (من ١ إلى ١٠٠، الافتراضي ٢٥) وتُعيد data و links و meta.

احصل على مفتاح API

يُفعّل مالك مساحة العمل الوصول وينشئ المفاتيح من التطبيق ← المطوّرون (سجّل الدخول للوصول إليها). تظهر المفاتيح بصيغة sk_live_ab12cd34.••• وتُعرض مرّة واحدة. يمكنك تقييد المفتاح بصلاحيات (مثل القراءة فقط) وإبطاله في أي وقت.

المصادقة

كيف أصادِق الطلبات؟

أرسل مفتاحك كـ Bearer token في ترويسة Authorization مع كل طلب. الطلبات دون مفتاح صالح تتلقّى 401؛ والمفتاح الذي تنقصه الصلاحية المطلوبة يتلقّى 403.

curl https://syrianfatora.com/api/public/v1/customers \
  -H "Authorization: Bearer sk_live_ab12cd34.your_secret_here"

الصلاحيات

كل مفتاح مُقيَّد بصلاحيات لكل مورد. القراءة (GET) تتطلّب {resource}.read؛ والكتابة (POST / PUT / DELETE) تتطلّب {resource}.write. والمفتاح الذي تنقصه الصلاحية يتلقّى 403.

كل الاستجابات بصيغة JSON. القوائم مُقسّمة إلى صفحات ومغلّفة بالشكل { "data": [...], "links": {...}, "meta": {...} }. والسجل المفرد مغلّف بالشكل { "data": {...} }.

وحدة الاختبار الحيّة

ألصق مفتاحًا ونفّذ طلبات حقيقية على مساحة عملك. يبقى المفتاح في متصفّحك (يُرسَل فقط إلى واجهة هذا الموقع، ولا تخزّنه هذه الصفحة على أي خادم).


                        

                    

                    
استخدم مفتاح قراءة فقط هنا إن كنت تريد الاستكشاف فحسب — فطلبات الكتابة تُنشئ أو تُعدّل أو تُبطل سجلات حقيقية في مساحة عملك.

                


                
                

                    
الحدود والحصة

                    
ما هي حدود الطلبات؟

                    
كل طلب ناجح يُحتسب من حصة مساحة عملك ويُسجَّل. ويُطبَّق حدّان:


                    
الحصة اليومية

                    
لكل مساحة عمل حدّ يومي للطلبات (الافتراضي 1000، ويمكن رفعه عند الطلب). عند بلوغه تُعيد الطلبات 429 حتى اليوم التالي.


                    
حصة الباقة الشهرية

                    
تضيف الباقات المدفوعة حصة شهرية تُقاس عبر دورة الفوترة. وما دام التطبيق مجانيًا فهي تُسجَّل لكنها لا تمنعك أبدًا.


                    
ترويسات الاستجابة

                    
كل استجابة تحمل وضعك الحالي؛ كما يخبرك 429 بموعد إعادة المحاولة.

                    

                        

                            
الترويسةالمعنى

                            
                                
X-RateLimit-Limitالحدّ اليومي لمساحة عملك.

                                
X-RateLimit-Remainingالطلبات المتبقية اليوم.

                                
Retry-Afterالثواني المطلوب انتظارها قبل إعادة المحاولة (تُرسَل مع 429 فقط).

                            
                        

                    


                    
التسجيل

                    
كل طلب — بما في ذلك المرفوضة بـ 429 — يُسجَّل ضمن استخدام مساحة عملك وسجل التدقيق.

تحقّق من التوقيع

                    
نوقّع قيمة X-Webhook-Timestamp ثم "." ثم محتوى الطلب الخام بسرّ نقطة الاستقبال (يظهر مرّة واحدة عند إنشاء الـ webhook) باستخدام HMAC-SHA256. أعِد احتسابه وقارن — وارفض الطلب إن لم يتطابق، وارفض الطوابع الزمنية الأقدم من بضع دقائق لمنع إعادة التشغيل.

                    

                        
                        
                    

                    

                        
$secret  = 'whsec_your_endpoint_secret';
$payload = file_get_contents('php://input');           // raw body
$ts       = $_SERVER['HTTP_X_WEBHOOK_TIMESTAMP'] ?? '';
$expected = 'sha256=' . hash_hmac('sha256', $ts . '.' . $payload, $secret);
$received = $_SERVER['HTTP_X_WEBHOOK_SIGNATURE'] ?? '';

// Reject forgeries and stale replays (timestamp older than ~5 minutes).
if (! hash_equals($expected, $received) || abs(time() - (int) $ts) > 300) {
    http_response_code(403);
    exit;
}
// trusted: json_decode($payload, true) and act on it. Return 2xx.

                        
const crypto = require("crypto");

// Verify against the timestamp + RAW body, before JSON parsing.
function verify(rawBody, header, timestamp, secret) {
  const expected = "sha256=" + crypto.createHmac("sha256", secret)
    .update(timestamp + "." + rawBody).digest("hex");
  const a = Buffer.from(expected), b = Buffer.from(header || "");
  if (a.length !== b.length || !crypto.timingSafeEqual(a, b)) return false;
  return Math.abs(Date.now() / 1000 - Number(timestamp)) < 300; // reject replays
}

                    

                    
نعيد محاولة التسليمات الفاشلة بتباعد متزايد (حتى ٥ محاولات). استجب بـ 2xx بسرعة للإقرار، ونفّذ العمل الثقيل لاحقًا بشكل غير متزامن.

                


                
                

                    
الأخطاء

                    

                        

                            
الحالةالمعنى

                            
                                
200 / 201نجاح

                                
401مفتاح API مفقود أو غير صالح

                                
403المفتاح تنقصه الصلاحية المطلوبة، أو وصول مساحة العمل غير مُفعّل

429تجاوز حد الطلبات (الحصة اليومية لمساحة العمل)

الأسئلة الشائعة

                                            

                            
                                كيف أصادِق طلبات الواجهة؟
                                
                            
                            
أرسل مفتاح مساحة عملك كـ Bearer token في ترويسة Authorization مع كل طلب: Authorization: Bearer sk_live_…. الطلبات دون مفتاح صالح تُعيد 401، والمفتاح الذي تنقصه الصلاحية المطلوبة يُعيد 403.

                        

                                            

                            
                                كيف أحصل على مفتاح API؟
                                
                            
                            
يُفعّل مالك مساحة العمل الوصول وينشئ المفاتيح من «التطبيق ← المطوّرون». يظهر المفتاح مرّة واحدة فقط، ويمكن تقييده بالقراءة فقط أو الكتابة، وإبطاله في أي وقت.

                        

                                            

                            
                                ما هي حدود الطلبات في الواجهة؟
                                
                            
                            
لكل مساحة عمل حصة يومية للطلبات (1000 افتراضيًا، وتُرفع عند الطلب) وحصة شهرية على الباقات المدفوعة. تُعيد كل استجابة X-RateLimit-Limit و X-RateLimit-Remaining؛ وعند بلوغ الحصة تُعيد الطلبات 429 مع ترويسة Retry-After.

                        

                                            

                            
                                لماذا أتلقّى الخطأ 401 أو 403؟
                                
                            
                            
الخطأ 401 يعني أن مفتاح API مفقود أو غير صالح. والخطأ 403 يعني أن المفتاح صالح لكنه يفتقر إلى الصلاحية التي يحتاجها المسار (مثل customers.write)، أو أن وصول الواجهة لمساحة العمل غير مُفعّل.

                        

                                            

                            
                                كيف تبقى الـ Webhooks آمنة؟
                                
                            
                            
نوقّع قيمة X-Webhook-Timestamp مع محتوى الطلب الخام بسرّ نقطة الاستقبال باستخدام HMAC-SHA256 ونرسله في X-Webhook-Signature. أعِد احتساب التوقيع لديك، وارفض أي طلب لا يتطابق توقيعه، وارفض الطوابع الزمنية القديمة لمنع إعادة التشغيل.

                        

                                            

                            
                                هل أحتاج إلى حساب إجماليات الفاتورة؟
                                
                            
                            
لا. تُحتسب الإجماليات والضريبة والخصومات دائمًا في الخادم. ترسل الكميات وأسعار الوحدة و(للعملات الأجنبية) سعر الصرف — لا الإجمالي.
